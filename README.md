# stock-price-predicator
A Streamlit app that shows live stock candlestick charts and predicts the next 7 days using machine learning.

## Features
- Live data from Yahoo Finance (yfinance)
- Candlestick chart with 20-day moving average (Plotly)
- Price forecast with scikit-learn

## Run locally
pip install -r requirements.txt

python -m streamlit run app.py

## Tech
Python, Streamlit, yfinance, Plotly, scikit-learn, pandas

## Note
This is a learning project, not financial advice.
